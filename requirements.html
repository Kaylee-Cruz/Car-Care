BR-06Unlisted vehicle models require admin review before service scheduling.owner.html — pending vehicle submission; admin.html — Pending vehiclesSubmit an unlisted vehicle, then approve it in Admin to unlock scheduling.

C-03Vehicle model data must not be static.admin.html — Add new model; data stored in localStorageAdd a make/model/year and verify it appears in the catalog and owner picker.
C-04The system provides an ongoing way to add new vehicle model data.admin.html — Add new model and Import new model yearAdd a new model or import a batch of models for another year.
